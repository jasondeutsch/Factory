# Sources and adaptation

Reviewed 2026-10-18.

Selected working principles are adapted from [Chris Graffagnino's software-architect skill](https://github.com/Chris-Graffagnino/software-architect/blob/main/SKILL.md), whose metadata identifies version 1.1.0. The upstream [MIT license](https://github.com/Chris-Graffagnino/software-architect/blob/main/LICENSE) is retained locally in `LICENSE`.

The adaptation keeps problem framing, tradeoff reasoning, complexity awareness, repository evidence, and explicit uncertainty. It replaces the upstream interaction workflow with Factory's existing roles and approval process. It does not include Spec-Kit integration, mandatory reference loading, prescribed saga choices, or the upstream book-summary reference collection. The local references are focused guidance written for this toolbox, not excerpts from the books named upstream.

Additional external references:

- [C4 model diagrams](https://c4model.com/diagrams), Simon Brown: selecting useful views and diagram scope. No example diagrams or site content are copied into this toolbox.
- [arc42 overview](https://arc42.org/overview/), Peter Hruschka and Gernot Starke: architectural documentation topics. The arc42 template is not bundled or reproduced.

These are local adaptations, not an installed upstream package or an automatically updating dependency. The review date and source version identify the material consulted; they are not a pinned Git revision.
